# 06 · 产品框架

> Vibe_helper Stage 6 产出(产品视角);技术视角见 07

## 一、信息架构(3 视图)

```
首页 (home)
├── 顶栏:品牌「秒策 · 企业活动策划工作台」 + [AI 设置⚙] 
├── 主区:
│   ├── 快速开始区:「+ 新建活动策划」大按钮
│   ├── 八大模板卡片区(4×2 网格,图标+名称+一句话说明)
│   └── 历史方案区(搜索/类型筛选 + 方案卡列表 + 归档折叠区)
└── 空状态:引导文案 + 箭头指向新建按钮

向导 (wizard,三步固定)
├── Step1 基础信息:一页表单(分组:基本信息/时间安排/地点与人群/预算与需求)
│   ├── 条件字段区(节日→具体节日;发布会→产品名称)
│   └── 底部:[上一步·无] [下一步:生成方案]
├── Step2 生成中:10 模块清单逐个点亮(勾选+进度),完成自动跳转
└── Step3 预览编辑 → 即编辑器视图

编辑器 (editor)
├── 左侧:模块导航(一~十,锚点定位,标记"已编辑/AI 生成"角标)+ 方案信息摘要
├── 主区:10 个模块卡片
│   ├── 卡片头:编号+标题+状态角标 + 操作区[编辑|重新生成|润色|精简|扩写|复制]
│   └── 卡片体:公文式渲染(小标题/表格/列表)
├── 卡片编辑态:textarea(Markdown 源) + [保存][取消][撤销上一步]
└── 顶栏:[← 返回首页] 方案名(可改) [导出 Markdown][打印]
```

## 二、核心用户流

1. **新用户首访**:首页 →(空状态引导)→ 新建/选模板 → Step1 填表(必填校验)→ Step2 自动生成 → 编辑器 → 导出 → 回首页看到方案已自动保存
2. **回头用户**:首页历史列表 → 打开 → 只重生成"宣传文案"模块 → 撤销 → 导出
3. **进阶用户**:AI 设置配好私有网关 → 对"主持词"点扩写 → 满意保留,不满意撤销

## 三、模块卡交互态设计

| 状态 | 表现 |
| --- | --- |
| 默认 | 渲染态,操作区常驻 |
| 编辑中 | textarea + 保存/取消;其他模块不受影响 |
| 生成中(重生成/润色等) | 卡片头部 spinner,操作区禁用,内容半透明 |
| 失败(AI 错误) | toast 显示原因,内容保持原样,可重试 |
| 已编辑(手动) | 角标"已编辑";已 AI → 角标"AI 生成";可撤销回到上一版 |

## 四、文案基调(界面用语)

- 动词直白:「生成方案」「重新生成」「导出 Markdown」,不卖弄
- 空状态给方向:历史为空 → "还没有方案,从右上角或下面选一个模板开始"
- 错误不道歉、说明怎么办:AI 失败 → "接口连接失败:网络错误。已保留原内容,可在设置中检查接口地址"
- 未配置 AI 的按钮:"润色(AI)——需先在右上角设置中配置接口"

## 五、视觉方向(依 frontend-design/taste-skill 规范)

- **基调**:企业极简专业、浅色办公风;主色高级蓝(深钴蓝系 #1444C4,非默认框架蓝),墨色文字 #101828,冷灰纸面背景 #F5F7FA,琥珀 #D97A16 仅作预算警示,绿 #157F4C 仅作通过/成功
- **签名元素**:①模块卡采用**公文编号体系**(一、二、三…)+ 卡片头部细双线(红头文件式分隔的蓝色化转写),让生成物一眼"可提交";②导出/打印头带一枚**圆形"已核"印章**样式徽标(蓝色描边,克制使用,只出现在打印件页眉),把"企业正式感"做成记忆点
- **字体**:界面无衬线系统栈;方案正文标题用衬线(宋体系)强化公文气质——**正文衬线、界面无衬线的双轨制**是本产品版式个性所在
- **布局**:卡片式、留白克制、表格全宽斑马纹;动效只用于生成过程的逐模块点亮(工作流的仪式感),其余仅 hover 微交互
- 质量底线:响应式到移动端、键盘焦点可见、动画尊重 prefers-reduced-motion
