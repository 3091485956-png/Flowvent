# 04 · 用户声音挖掘

> Vibe_helper Stage 4 产出 · 来源:公开检索结果归纳(知乎问答/小红书笔记/招聘 JD/模板站评论的主题归纳)。为避免编造,本文件**不引用具体用户名与原文链接**,只保留可交叉验证的主题级结论;单条声音均已标注印证来源类型。

## 一、谁在喊痛(人群画像)

| 人群 | 场景 | 声音主题(多来源交叉印证) |
| --- | --- | --- |
| 雇主品牌/HR/行政 | 季度团建、生日会、年会 | "一年要做 N 场活动,每场都从零开始" |
| 策划新手 | 第一次独立操盘 | "不知道一套完整方案该有哪些部分,老是漏" |
| 中小公司行政兼策划 | 无专职策划 | "老板今天说,明天就要方案,还得有预算表" |
| 活动公司执行 | 乙方快稿 | "客户要快、要全、要能改" |

## 二、痛点主题排序(按出现频次)

1. **"缺一漏十"**(最高频):写方案总漏东西——忘了安全预案、忘了复盘维度、物料清单和预算对不上。→ 印证:模板站"完整版"模板销量最高;知乎"活动策划包括哪些内容"类问题长期有流量
2. **"通用 AI 不敢直接交"**:格式每次不一样、表格算不平、AI 会自己编预算数字。→ 印证:豆包/Kimi 相关体验笔记中"还要自己再整理一遍"是高频抱怨
3. **"模板要改到脱皮"**:付费模板是 200 人规模,自己是 30 人;模板在三亚,自己在会议室。→ 印证:模板站差评关键词"太通用/数字对不上"
4. **"时间永远不够"**:从接到任务到交方案常只有 1~2 天,还要兼顾日常岗。→ 印证:招聘 JD 里"抗压、快节奏"与活动策划岗高度绑定
5. **"方案发出去就找不到了"**:Word 传微信,改了三版不知道哪版是终版。→ 印证:多维表格/网盘类工具在活动场景的渗透

## 三、用户在乎什么(价值点,按强度)

1. **成套、完整、结构标准**——"领导一眼觉得专业"压倒一切
2. **表格规整可算**——预算自动合计、物料数量对人数
3. **可改、可控**——AI 生成的东西必须能手动修,修了不能丢
4. **快**——分钟级出全案
5. **别折腾环境**——最好打开浏览器就能用,别装软件、别注册

## 四、对产品决策的直接影响(决策门结论)

| 用户声音 | → 产品决策 | 落在哪个模块 |
| --- | --- | --- |
| 缺一漏十 | 10 模块一次性成套,顺序固定,不许可删模块 | 生成引擎 |
| AI 不敢直接交 | 确定性模板引擎,AI 只做局部增强且可撤销 | 架构总纲 |
| 模板对不上 | 人数/时长/预算/场地参数驱动渲染缩放 | 表单+引擎 |
| 时间不够 | ≤3 秒全套生成 + 表单 2 分钟填完 | 性能指标 |
| 版本混乱 | 方案自动保存+落盘管理+一键导出 MD | 方案管理 |
| 别装软件 | 纯前端静态应用,双击即用 | 技术选型 |

**结论:痛点真实、高频、有付费参照(模板站),且现有工具无一同时满足"成套+可控+快"。值得做,且必须把"确定性"做成第一卖点。**
