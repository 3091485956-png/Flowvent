# 09 · 个性化与记忆方案("越用越懂你")

> 状态:方案设计,未动代码 · 2026-09-30
> 一句话:让产品从"通用模板引擎"进化为"带着组织记忆的策划搭档"——但**学到的只进参数,不进结构**,零幻觉承诺不破。

---

## 一、目标与红线

### 目标(用户原话翻译成产品语言)
1. **有归属门槛**:不是随便来个人就能用 → 组织工作区概念
2. **懂需求**:越用越知道该出什么策划案 → 使用模式学习 + 预填/推荐
3. **懂风格**:知道用户喜欢什么风格方式 → 偏好画像(被动信号 + 主动确认)
4. **懂价值观**:知道公司价值观是怎样的 → 组织档案(价值观词汇表 + 禁忌清单)

### 红线(与既有架构的和解,不可违背)
| 红线 | 含义 |
| --- | --- |
| **记忆只进参数,不进结构** | 学习结果只影响"选哪个变体、填什么词、按什么系数",10 模块结构、公文骨架、表格格式永不改变 |
| **一切记忆仅存本地** | 不上传、不联网同步;AI 接口调用时默认不携带记忆,可选开关"附带组织风格上下文"且明示 |
| **记忆透明可控可删** | 所有学习结论在「偏好中心」可见、可勾选否决、可一键"忘记一切";绝不做用户不知情的画像 |
| **不偷偷收录用户内容** | 用户编辑过的环节/文案只有显式点"存为我们的标准"才进入记忆,不静默采集 |

---

## 二、四层记忆模型

```
┌─────────────────────────────────────────────────────────┐
│                     记忆层(memory.js)                    │
│                                                          │
│  L1 组织档案 OrgProfile    —— 这家公司是谁(价值观/禁忌)   │
│  L2 偏好画像 Preferences   —— 这群人喜欢什么(风格/档位)   │
│  L3 变体权重 VariantStats  —— 哪些内容总被保留(加权选择)  │
│  L4 使用模式 UsagePatterns —— 接下来大概率要办什么(推荐)  │
└──────────────────────┬───────────────────────────────────┘
                       ↓ 只作为参数注入
┌──────────────────────▼───────────────────────────────────┐
│        确定性生成引擎(结构不变,零幻觉承诺保持)             │
└──────────────────────────────────────────────────────────┘
```

### L1 组织档案 OrgProfile ——「用户公司的价值观是怎样的」

**字段**(全部可空,可后补):
- 基础:行业、规模段(<50/50-200/200-1000/1000+)、城市(触发预算城市系数)
- **价值观关键词 3-5 个**:如「务实」「用户第一」「坦诚」「长期主义」→ 注入文案语气与主持词(例:主持词开场从通用煽情改为"过去一年我们把『务实』两个字落在了 37 个项目上")
- **称谓习惯**:同事/伙伴/同学/同学+花名 → 全部文案与主持词统一
- **禁忌清单**(结构化,不是自由文本):禁酒 / 不做高风险户外 / 素食占比 / 无酒精饮料 / 不办夜间活动 / 涉外语言(中英双语文案)→ **硬约束**:安全预案自动增删条目、环节库自动过滤、餐饮预算自动调整
- 审批习惯:预算颗粒度(要不要分项到元)、是否必须附比价说明

**来源**:首次引导一页表单(可跳过)+ 从历史方案表单静默沉淀(城市、预算档位、人群结构)+「组织档案」随时编辑。

### L2 偏好画像 Preferences ——「喜欢什么风格方式」

**被动信号(零打扰,自动记录)**:
| 信号 | 解读 |
| --- | --- |
| 某模块手动编辑率/编辑幅度 | 编辑越多 = 生成越不贴合 → 该模块下次优先用"保守基线版" |
| 重新生成后保留的变体编号 | 被保留的变体特征(如"游戏规则更详细的那版")升权 |
| 撤销率(AI 润色/扩写被撤销) | AI 风格不受欢迎 → 降低自动建议 |
| 精简使用分布 | 用户偏好短句 → 文案模块默认精简版起步 |
| 导出前最后修改 | 最终态才是真偏好,中间态不算 |
| 时长/预算/人群的历史选择分布 | 向导预填默认值(如:总是选"半天"、人均 80-120) |

**主动确认(不猜到底,月度一次)**:
- **偏好确认卡**:系统把学到的结论用人话列出——"我注意到你们偏爱:① 半天场 ② 人均 100 左右 ③ 文案偏活泼 ④ 环节规则写得比默认详细"——用户逐条 ✓/✗/改。✗ 的项立即失效并降权信号来源。
- **导出后轻反馈**(可选,一次性):"这份方案哪里最有用?"三选项(结构完整/文案能直接发/预算够准),结果进入模块信任度。

**风格维度**(画像的输出形态,引擎消费):文案语气 ∈ {正式公文, 活泼, 克制极简}; 表格颗粒度; 环节类型偏好权重 {团队竞技, 轻社交, 文化手作, 学习型}; 预算档位区间; 时长倾向。

### L3 变体权重 VariantStats ——「你们公司的团建长这样」

- 每个内容包的每个环节变体维护计数:`被生成次数 / 被保留次数`(保留=导出时仍在或重生成停在它)。
- 选择器从 `pickTick 轮换` 升级为 `pickWeighted`:**同参数下结果仍确定**(权重排序 + tick 打散次序),只是高保留率变体优先——确定性不破,契合度上升。
- 时间衰减:一年前的信号权重减半(组织会变)。
- **自定义环节库**:用户编辑出满意的游戏规则/环节后,点「存为我们的标准环节」→ 进入公司自定义环节库(显式动作),下次生成优先编排,并标注「贵司标准」。

### L4 使用模式 UsagePatterns ——「越用越懂你需要什么策划案」

- **规律识别**:生日会每月一场?团建固定季度末?→ 首页「下次策划」卡片:"距你们惯例的 Q4 团建还有 3 周,去年是两天一夜户外,人均 210。一键开始(已预填)"。
- **类型组合统计**:该公司最常办的类型 × 人群 × 时长 → 向导默认值全面预填。
- **方案复用**:某方案被复制/导出 ≥2 次 → 提示「沉淀为公司模板」(存整套 form+模块基线,下次从模板新建,日期/人数自动更新)。
- 全部本地计算,无提醒推送(无后端,纯打开产品时呈现)。

## 三、准入与工作区 ——「不是随便来个人就能用」

**设计取向:软门槛 + 组织身份,不做硬注册**(零后端承诺不破)。

1. **首次进入**:三步极简引导——① 命名工作区(默认公司名)② 一页组织档案(可跳过,明确提示"完善后方案更贴合")③ 开始使用。未建工作区前,首页模板卡可见但点击时引导建档(**可"先看看"进入只读演示,生成动作需建档**)。
2. **工作区 = 组织身份**:档案、偏好、自定义模板、历史方案全部挂在当前工作区下;支持多工作区切换(行政同学服务多公司/集团多子品牌的真实场景),切换需口令(本地存,防同机误切,**诚实定位:防误用不防恶意**——localStorage 无真安全,文档明示)。
3. **价值而非墙**:门槛的真正目的是让"数据长在组织身上、越用越厚",而不是把人挡在外面——演示可看、建档即用、档案越全方案越准,形成自然留存。

## 四、关键交互(用户视角的完整旅程)

```
首次:建档向导(1 分钟)→ 生成即带组织称谓/价值观/禁忌
日常:向导预填越来越准 → 编辑/重生成/导出 → 信号静默沉淀
每月:偏好确认卡(30 秒,✓/✗ 学到的结论)
沉淀:满意环节显式存库 → 方案导出 2 次提示沉淀模板
进化:首页"下次策划"推荐卡 → 一键带记忆新建
控制:偏好中心——查看全部记忆、逐项否决、一键遗忘、导出记忆备份(JSON)
```

## 六、分期路线(每期可独立交付验收)

**P0「懂价值观」(建议先行)**:工作区 + 组织档案(价值观/称谓/禁忌/城市系数)+ 禁忌硬约束 + 旧数据迁移。
验收:同一表单,填/不填档案生成对比,称谓与禁忌差异可见;`node test/run.js` 新增禁忌过滤与确定性断言全绿。

**P1「懂风格」**:被动信号采集 + 变体加权选择 + 向导预填 + 偏好确认卡 + 偏好中心(可删)。
验收:连续 3 次保留同一变体后,新方案默认采用该变体;确认卡否决某偏好后立即生效;一键遗忘后信号清零。

**P2「懂需求」**:使用模式推荐卡 + 自定义环节库 + 方案沉淀为公司模板 + 记忆备份导出。
验收:第二次导出同一方案后出现沉淀提示;从模板新建自动更新日期人数;推荐卡按历史规律出现。

## 七、风险与对策

| 风险 | 对策 |
| --- | --- |
| 记忆污染(错误偏好越积越偏) | 确认卡人工裁决为一票否决;信号时间衰减;偏好中心一键重置 |
| 破坏确定性卖点 | pickWeighted 保持"同 mem 同结果";测试加"同输入两次生成一致"断言 |
| 门槛劝退新用户 | 演示可看 + 建档 1 分钟 + 全字段可跳过 |
| localStorage 容量(记忆+多工作区) | 记忆为 KB 级无压力;方案库大时触发 IndexedDB 迁移(backlog 已列) |
| "懂你"变成"吓你"(画像恐惧) | 全部结论人话呈现、可删、永不离开本机——写进产品文案 |

## 八、明确不做

- 账号体系/云端同步/团队协作(需后端,违背零后端承诺,列 backlog)
- AI 自动改结构/自动扩模块(违背零幻觉)
- 隐式采集用户编辑内容入库(必须显式"存为标准")
- 推送通知(无后端,打开产品时呈现)
